FAQ

 

Is this medical advice?

No. Iron Code is a research and educational reference only. It is not medical advice, not a treatment guide, and not a substitute for a licensed healthcare professional. Many compounds described are not FDA-approved. It is intended for adults 21 or older.

Do I have to install it?

No. You can use the full free edition directly in your browser — nothing to install. The download is only if you want to run it offline as a desktop app. Both are the same free edition with the same content.

Why does Windows warn me when I run it?

Independent software without an expensive code-signing reputation triggers SmartScreen’s “Windows protected your PC” prompt. Click More info → Run anyway. Verify the download with the provided SHA-256 checksum if you want assurance the file is intact.

What does Pro add?

Pro (coming soon) will unlock the study tools (reconstitution/dilution math helper, research-protocol reference views, compound combination references, and reminders). The full reference library is available now in the free version.

Do you collect my data?

No. The app works fully offline with no accounts, analytics, or tracking. See the privacy policy.
